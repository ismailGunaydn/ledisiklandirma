## 📍 Hakkımızda

**Led Işıklandırma**, Türkiye’nin önde gelen profesyonel yılbaşı ışık süsleme ve LED dekorasyon firmalarından biridir. 2009 yılından beri villa, AVM, otel, belediye, cadde ve kamusal alan projelerinde anahtar teslim hizmet sunuyoruz.

- **15+ yıl deneyim**
- **500+ tamamlanmış proje**
- **Türkiye geneli hizmet** (81 il + tüm ilçeler)
- **Tek elden hizmet**: Keşif → Tasarım → Üretim → Montaj → Bakım → Söküm
